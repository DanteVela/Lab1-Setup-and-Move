# lab01-setup-and-move-DanteVela
lab01-setup-and-move-DanteVela created by GitHub Classroom

In this lab, we learn how to clone a repository and create a Unity Project thats 2D with various movement methods (Keyboard, MouseClick Position, Orbit Object).
We then put in some clear images that will be adjusted accordingly and have code implemented later on.

After the images are done being adjusted, we can proceed into implementing code into our images:
Using Debug.Log to see how it works in Start and Update functions.
The Keyboard movement will be used on the original image where it goes based on the direction of the WASD keys.
The MouseClick Position movement will be used on image (1) where it goes based on the position of the MouseClick.

Bonus:
The Orbit Object movement will be used on image (2) where it goes around the original image with a specific radius, speed, and axis to help maintain stable orbit.
